# FTC-2025 Robot Code

Repository for the 2025 FTC season swerve robot with turret, shooter, and sorting capabilities.

## Features

- **Swerve Drivetrain**: 4-wheel swerve drive with field-centric control
- **Turret & Shooter**: Auto-aiming turret with velocity-controlled shooter and adjustable hood
- **Intake & Sorting**: Color sensor-based ball sorting with lopata (shovel) servos
- **Modular Architecture**: Clean subsystem-based code organization

## Quick Start

1. Open the project in Android Studio
2. Configure hardware names in `RobotHardware.java`
3. Deploy to your robot
4. See [TeamCode/README.md](TeamCode/README.md) for detailed documentation
